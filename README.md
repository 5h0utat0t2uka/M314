# M314 Motion Tracker 
![Motion Tracker](./docs/ss.png)  

This project uses [HLK-LD2450](https://www.hlktech.net/index.php?id=1182) and [M5Stack CoreS3](https://docs.m5stack.com/en/core/CoreS3) to build the [M314 Motion Tracker](https://avp.fandom.com/wiki/M314_Motion_Tracker?file=Motion_Tracker_detects_one_signal.png) display, sound effects and sensing — that USCM equipment featured in the movie *Aliens (1986)*.  

You can experience the vibe of the film — "anytime, anywhere"!

> [!TIP]  
> According to the HLK-LD2450 specs, it can sometimes detect motion even on the backside of the sensor.  
> If you want really high detection accuracy, you'll need some hardware tweaks to suppress reflections.
